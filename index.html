RegionAlign

A malicious model provider reorders a quantized model's weights — changing no value — so a single bit flip in one memory region cripples it.

The reorder is a function-preserving channel permutation: clean accuracy and perplexity are unchanged, so the model passes every quality check. Only the memory layout changes. RegionAlign packs the model's most vulnerable weights into one pre-chosen region, so one localized fault there is far more damaging than on the original layout.

One in-region bit flip: StableLM2-1.6B perplexity 11.5 → 68.3. The original layout barely moves.

01The problem

Two attacks, never combined before

Model supply-chain tampering and hardware fault injection have been studied in isolation. RegionAlign connects them: the first sets up the second.

Threat A · supply chain

A tampered model

A third-party provider ships the model. It answers correctly, so it looks safe — but the provider can hide a change that only triggers later.

Threat B · hardware

A localized fault

With physical access, an attacker flips weight bits in one small memory region — for example by electromagnetic fault injection (EMFI).

RegionAlign uses Threat A to prime Threat B.

02The idea

The layout is the attack — not the values

A few weights are vulnerable: flip one bit and the model collapses. Normally they are scattered across memory, so one localized fault hits almost none.

A channel permutation reorders the weights — the model stays mathematically identical — and lands the vulnerable ones inside one target region. The trap is the arrangement alone.

Like packing a crate

Same items in, nothing added or removed — so it weighs the same and passes inspection. But every breakable item is moved to one corner. Now a single knock there shatters far more than before.

03Method

Three steps — no retraining, no changed values

Rank the vulnerable bits

A sensitivity-guided search finds the bits whose flip raises the loss most, under a fixed search budget.

Concentrate them by permutation

Channel permutations move those weights into one aligned 4 KB region, preserving every weight value and the model's function exactly.

Pass the clean gate

Each layout must match the original's clean accuracy and perplexity before it is used — so the tampering is invisible to task-performance checks.

04The attacker's edge

Invisible, cheap, and concentrated

Invisible

Passes every check

Identical clean accuracy and perplexity. A user who evaluates task performance sees nothing wrong.

Cheap

No retraining, no new values

Weight values, quantization, and the inference pipeline are untouched. The provider only permutes channels.

Concentrated

One region is enough

Damage is packed into a single region, so one localized fault does what scattered bit-flip attacks need many injections to achieve.

05What we found

Identical when clean. Broken when hit.

We compare three layouts under a matched region, fault budget, and search budget: the original, the attacker's RegionAlign layout, and a random permutation outside the attacker's control. Clean, all three are the same. After the same in-region bit flips, RegionAlign degrades far more.

Vision-language models fall off a cliff

For Qwen2.5-VL-3B, a single in-region bit flip under RegionAlign drops the VQA score on both tasks below 1 (out of ~60 and ~88 clean) — while the original and random layouts stay near clean under the same fault.

Why: almost all selected flips hit the most-significant bit of a near-zero weight. The permutation moves weights whose rows allow large values into the region, so one flip swings them hard — leverage the other layouts don't have there.

07The honest limit

Hitting one region physically is hard — and that is the point.

On real hardware (an NVIDIA Jetson AGX Thor), EMFI corrupts stored INT8 weights in both directions, as our threat model assumes. But across 2,500 attempts, none landed on the pre-registered target. RegionAlign's power is not that physical aiming is easy — it is that once the attacker is confined to a region, the chosen layout decides how much damage a fault there can do.
